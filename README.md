# jsonfmt — JSON Formatter & Validator

Format, validate, minify, and explore JSON — all in your browser. Nothing leaves your machine.

- **Format** — Pretty-print JSON with syntax highlighting
- **Minify** — Compact JSON to save bytes
- **Validate** — See exact error location (line, column, context)
- **Syntax highlighting** — Keys, strings, numbers, booleans, null all color-coded
- **Keyboard shortcut** — `Cmd+Enter` / `Ctrl+Enter` to format

## Usage

Open [neocrev.github.io/jsonfmt](https://neocrev.github.io/jsonfmt/), paste your JSON, click **Format**.

Or run locally — open `index.html` in any browser.

## Tech

Zero dependencies. Single HTML file. Everything runs client-side.
